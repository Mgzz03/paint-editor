# CIE202 Paint Editor

A C++ graphics editor project with shape drawing, selection, transformation, file operations, undo/redo, copy/paste, fill, zoom, and play-mode operations.

## Features

- Lines, circles, squares, triangles, and irregular polygons.
- Move, resize, rotate, duplicate, delete, hide, unhide, and fill operations.
- Save/load support and undo/redo actions.
- A controller-driven interactive interface built on the supplied CMU graphics library.

## Build

Open `CIE202-project.sln` with Visual Studio and build the solution using the C++ desktop workload. The bundled graphics library is excluded from this portfolio copy because it is a third-party dependency; configure its include and library paths locally.

This is an academic graphics project and has been published as source for review rather than as a packaged executable.
